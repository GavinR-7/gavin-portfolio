## Context

Cornell Canvas gives students no API tokens, and my deadlines live in three places: Canvas, Gradescope and Ed. I wanted one list of what is due and one way to save a course's files, without a tool that holds my login or sends my coursework to a server.

## What it is

A Chrome extension that works around the missing tokens by reusing the signed in browser session. It uses a read only, GET only client and has no backend, account or telemetry.

- Merges due dates from Canvas, Gradescope and Ed Discussion into one deduplicated list.
- Includes an incremental course file archiver (File System Access API, per course manifests) that re-downloads only changed files.
- Each source fails on its own, so one outage never blanks the rest.

## Security

I hardened it against credential leakage: exact origin checks on server supplied URLs, cookie less file downloads, redirect capped image fetches, and no network from the popup off Canvas. It is covered by 492 automated tests across 38 files, plus type checking and a clean production build.
